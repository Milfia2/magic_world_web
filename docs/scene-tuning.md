# 場景與角色位置調整

## 立繪的大小、位置

編輯 `js/character-spawns.js` 的 `SPAWN_POINTS`。每個地點有數個候選位置；系統每三小時分配角色與位置。同一時段重新整理、進出場景或調整視窗不會重抽。

```js
{ name: '左側長廊', x: 12, y: 79, height: 31 }
```

- `x`：腳底中心距原始背景左緣的百分比，增加往右。
- `y`：腳底距原始背景上緣的百分比，增加往下。
- `height`：角色高度占背景原圖高度的百分比，增加變大。
- `name`：方便辨識的名稱，不顯示在遊戲中。

例如把 `x:12` 改成 `x:17` 就往右移；把 `height:31` 改成 `height:25` 就縮小。位置以原圖為準，不是瀏覽器截圖：背景採底部對齊，桌面與角色同步縮放。寬螢幕會裁掉背景上方，候選位置建議放在地面且預留頭頂、左右與姓名標籤空間。

`CHARACTER_SCALE` 可微調單一角色的整體大小；最終高度是 `height × CHARACTER_SCALE`。`gaile` 是蓋勒 Caleb 的既有素材／存檔 ID，不要直接改名。每個共用地點目前保留四個候選位置，新增地點或刪減位置時，應保留至少四個位置，避免多人同時抵達沒有位置可用。

重新整理網頁即可看到設定更新；無須清除進度。若目前該處無人，可查看 `schedule.js` 的 `scheduledRoster()` 結果或等待下一時段；不要為了預覽改動存檔。可用終端機唯讀檢查當前行程：

```sh
node --input-type=module -e "import {scheduledRoster} from './js/schedule.js'; console.table(scheduledRoster().map(p=>({角色:p.id,地點:p.scene,位置:p.point.name})));"
```

## 出現地點與時段

同一份檔案的 `LOCATION_PREFERENCES` 控制地點權重。數值越高越常去，不代表固定百分比；省略地點就不會出現。私人房間只填自己的 `room/角色ID`。

目前依角色設定：艾比偏好教室、中庭、球場；西婭偏好森林、中庭、村莊；蓋勒偏好天文臺與圖書館；澤菲爾偏好球場、中庭。21:00–06:00 的自己房間權重提高為三倍。

以裝置當地時間在 00、03、06、09、12、15、18、21 時更換行程；同日相鄰時段不選同一地點，跨午夜可能仍留在原地。無後端、無跨時區同步。網頁開著時每 15 秒檢查一次，對話或飛行遊戲中不強制中斷，結束後更新。

每位角色每時段只有一個所在地，因此許多場景會沒有人。操縱角色不作為一般場景 NPC 出現，也不出現在自己的房間；校園總地圖不顯示任何角色。只有 Q 版大廳與魁地奇遊戲顯示完整四人。

自己的房間直接開放，其他角色不會進來。玩家必須在一般場景找到本人，交談後按「去房間看看」同行；房內固定顯示主人的放大立繪，不受當前排程影響。離開房間、切換角色或重新整理都取消本次拜訪；舊存檔的 `met` 只是相遇紀錄，不是鑰匙。Q 版大廳與飛行遊戲聊天不提供邀約。邀約若跨三小時換班時段，需重新交談。

放大立繪的腳底位置和高度在 `js/room-content.js` 的 `ROOM_HOST_POINT`，並限制高度不超過場景的 84%，避免寬螢幕裁掉頭頂。`ROOM_REACTIONS` 是四位主人對日記、小物、窗戶的反應；房間內點小物先觸發主人回應，再由玩家決定是否收下，不再直接拿走。

這是單機靜態遊戲的拜訪規則，不是伺服器權限保護。圖片、台詞和 TXT 發布後仍是公開網站資源，請勿放入真實私人資料。

## 可點選物品

編輯 `js/scene-layout.js`：`sceneObjects` 是一般場景物品，`roomObjects` 是房間的日記與小物。此處 `x/y` 表示物品中心，`w/h` 是點擊範圍寬高，均為原圖百分比。與立繪的「腳底」基準不同。

`scene.css` 的 `.laid-record`、`.laid-map` 控制名冊／地圖的平放角度。沒有獨立圖片的物品沿用背景圖案並附微光，按「顯示互動提示」可查看點擊區域。

## 球場與角色文案

球場預設使用一般場景與三小時行程。按「開始魁地奇遊戲」才載入四張 `騎行_去背_…` 素材。遊戲支援方向鍵／WASD、拖曳、Q/E 遠近移動、遠近滑桿與觸控按鈕；切換飛行角色不會改變帶入角色。按「結束遊戲」回到目前時段的普通球場。

`js/dialogue.js` 是依提供的 Character Bible 編寫的情境草稿：分開保存場景台詞、12 組有方向的朋友關係、迷路／低落／贈禮反應。`js/data.js` 保存正式姓名、學院、生日、身高與擅長科目；立繪、一般場景不受衣櫥 Q 版／貓咪預覽造型影響。

## 點擊對話與初次招呼

場景不再自動冒出台詞；點角色才在對方頭頂顯示對話泡泡，不開中央彈窗。泡泡只顯示對方說的話，操縱角色保持沉默。點擊泡泡、角色與選項以外的區域會自動收起；再次點同一角色會換一句，若有其他可用內容就不立刻重複。對話選項與「去房間看看」放在場景下方；叉號、「結束對話」或 Escape 也可關閉。原先提供的四組台詞保存在 `js/ambient-dialogue.js` 的 `AMBIENT_LINES`，由「聊點日常」按鈕抽取。

`js/greetings.js` 的 `GREETINGS` 按「操縱角色 → 遇到的角色」保存 12 組招呼，僅有對方動作 `action` 與招呼 `text`，不包含玩家台詞。對方會依照玩家身分主動打招呼。存檔的 `greeted` 以角色配對記錄，換角色分開計算；重新整理不重複招呼。

## 宿舍半身對話介面

進房不會自動交談；點人物、日記、小物或窗戶才展開半身立繪與畫面下方半透明框。關閉可按「結束對話」、叉號或 Escape，之後恢復房間全身立繪與物品操作。閱讀完整日記仍使用獨立閱讀視窗。

在 `scene.css` 調整 `.conversation-bust`（半身區域大小／位置）、`.conversation-bust img`（裁切比例，190% 表示只顯示立繪上半段）、`.conversation-panel`（底部對話框）。`background:rgba(18,29,40,.78)` 最後的 `.78` 是不透明度，越小越透明。手機版有獨立尺寸與對話框捲動上限；場景中的原立繪只在對話時暫時隱藏，避免同一角色重複出現。

## 四份角色日記 TXT

可直接覆蓋以下 UTF-8 純文字檔，保留檔名即可：

- `content/diaries/abby.txt`：艾比。
- `content/diaries/thea.txt`：西婭。
- `content/diaries/gaile.txt`：蓋勒 Caleb（沿用既有 ID）。
- `content/diaries/zephyr.txt`：澤菲爾。

目前每份提供一篇示範草稿；第一行可寫標題，段落間空一行。讀取時原樣顯示換行，不執行 HTML。頂部「角色日記」讀取目前帶入角色的內容，拜訪時可在房間點主人的日記，由主人翻開給你看。舊版玩家自行輸入的日記仍保留在本機存檔，但新介面不再顯示或覆寫。

本機修改後重新打開日記即可；發布時 `node scripts/build.mjs` 會把 `content/` 一起放進 `dist/`。網站讀不到 TXT 時顯示重新讀取按鈕。
